Comment Console 使用方法（Windows x64）
========================================

一、启动软件

1. 请先把压缩包完整解压到一个普通文件夹，不要直接在压缩包里运行。
2. 双击“启动评论工作台.cmd”。
3. 程序会自动打开浏览器，工作台地址为：
   http://127.0.0.1:19422/app
4. 第一次运行会自动生成本机连接凭证，这是正常现象。

本软件已经自带运行环境，不需要另外安装 Node.js。


二、首次连接抖音

1. Chrome 浏览器需要先安装 Tampermonkey（篡改猴）扩展。
2. 在工作台右上角点击“使用教程”。
3. 点击“安装抖音连接脚本”，在 Tampermonkey 页面确认安装或更新。
4. 打开 https://www.douyin.com/ 并登录自己的抖音账号。
5. 刷新抖音页面，等待工作台右上角显示“抖音已连接”。

如果一直显示未连接：
- 确认 Tampermonkey 中“Bridge: Douyin”脚本已经启用；
- 确认 Chrome 扩展详情中已允许用户脚本；
- 重新安装一次连接脚本，然后刷新抖音页面。


三、配置 AI 模型

1. 打开工作台右上角“设置”。
2. 选择“使用自己的 API”。
3. 填写兼容 OpenAI 格式的 Base URL 和 API Key。
4. 点击“获取模型”，选择需要使用的模型；也可以手动填写模型名称。
5. 点击“发送 hi 并测试应用”，看到模型实际回复后再保存设置。

API Key 只保存在当前电脑的 config.json 中。不要把整个软件目录或
config.json 发送给其他人，以免泄露自己的密钥。

“使用平台服务”功能将在服务器版本完成后开放。


四、开始使用

1. 在“智能找客”中填写目标客户，例如：
   近期想购买演唱会门票、正在询问购票方式的人
2. 补充“视频搜索关键词”和“评论线索词”，例如“没抢到、求票、哪里买”。
3. 设置候选视频数、评论数和时间范围，然后点击“开始发现客户”。
4. 系统会先按互动量建立候选池，再抽样近期评论；结果中会显示质量分、近期样本和需求线索数。
5. 点击右上角“任务与历史”可以查看并打开每一次任务结果；关闭页面或重启软件后记录仍会保留。
6. 在线索审核页面检查 AI 判定结果和回复草稿，发布前请人工确认内容。

视频质量门槛可在“设置 → 视频质量筛选”中调整：
- 视频至少评论数：过滤几乎没有讨论的视频；
- 每视频抽样评论：抽样越多越准确，但任务时间也会增加；
- 抽样至少命中线索数：数值越高，入选视频越少、质量要求越严格。


五、关闭与再次启动

- 关闭启动时出现的黑色窗口即可停止本地服务。
- 下次仍然双击“启动评论工作台.cmd”。
- 如果提示工作台已经运行，程序会直接打开已有页面。


六、数据位置

- config.json：模型接口和本机连接配置，请勿分享。
- storage 文件夹：本地数据库和业务设置。
- logs 文件夹：运行日志。

软件默认只监听 127.0.0.1，不会把管理页面开放到局域网。


七、账号池与自动化工作流

1. 一个打开并登录抖音的浏览器标签页就是一个独立账号槽位；要加入多个账号，
   请分别在浏览器标签页登录并保持油猴连接脚本运行。
2. 在“账号池”中可以查看每个账号的连接方式、最近心跳和登录状态。
3. 在“自动化工作流”中创建规则：选择搜索词、评论线索词、要使用的账号，
   再选择评论、私信、点赞或关注动作。
4. 新规则默认“按间隔自动巡检 + 人工审核”。评论会保存为草稿，私信只会列出
   待审核数量，不会静默发送；确认规则安全后，才可以关闭审核并选择自动发布。
5. “消息聚合”是按账号分组的真实私信收件箱：左侧只列抖音私信会话，右侧按聊天气泡显示
   收发消息；来自评论区的内容只会作为该用户的“线索证据”，不会伪装成私信。
6. 收到私信后保持对应抖音标签页在线，工作台会自动轮询并保存到本地数据库；刷新或重启后
   仍能查看已保存的会话。选择会话后可直接发送真实抖音私信，发送结果也会进入同一条会话。
   如果还没有历史会话，可点击“＋ 新建私信”，选择账号、填写对方 UID 和首条内容，直接发起真实会话。
   当前只展示油猴桥接收到的实时私信和本系统发出的私信，不会用评论或虚构内容填充旧聊天记录。
7. 如果收件箱暂时为空，请确认对应抖音标签页已登录、油猴脚本已启用，并点击“刷新收件箱”。

自动评论和自动私信受每账号每日上限约束。请遵守抖音平台规则，先用小额度测试，
不要向没有明确需求的用户批量发送相同内容。
